About This Project:

The Insert Cloud is a project aimed at providing an alternative to the InsertService and AssetService:LoadAssetAsync(), offering a more streamlined way to insert Roblox assets. It simplifies the process of inserting assets into Roblox games and also doesnt have nearly as many restrictions as the traditional methods. Other noteworthy features are as follows:

  • Automatically (by default) sandboxes assets for safe script execution
  • Lets you load pretty much any Roblox asset directly into your game
  • Can be configured to suit different use cases
  • Automatically parses RBXM into JSON for easier integration and manipulation
  • Supports a wide range of asset types
  • Provides a RESTful API for easy integration with other services
